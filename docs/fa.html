دانلود فیلترشکن MezaVPN برای اندروید و ویندوز

MezaVPN (مزا وی پی ان) یک فیلترشکن و وی پی ان رایگان برای گوشی اندروید و کامپیوتر ویندوزی است؛ بدون ثبت‌نام و بدون تبلیغات. نسخه ۲ با کنترل‌های روشن، انتخاب کاربردی سرور و نمایش صادقانه وضعیت اتصال طراحی شده است.

MezaVPN چیست؟

MezaVPN یک فیلترشکن و اپلیکیشن VPN رایگان برای اندروید و ویندوز Native است که انتخاب خودکار یا دستی سرور و نمایش روشن وضعیت اتصال را ارائه می‌کند.

آیا فیلترشکن MezaVPN رایگان است؟

بله. MezaVPN برای اندروید و ویندوز رایگان است، به ساخت حساب کاربری نیاز ندارد و SDK تبلیغاتی ندارد.

MezaVPN را از کجا دانلود کنم؟

از صفحه رسمی انتشار MezaVPN در GitHub استفاده کنید. فایل APK اندروید، نصب‌کننده‌های x64 و x86 ویندوز و checksum در همان صفحه قرار دارند.

چه سیستم‌هایی پشتیبانی می‌شوند؟

MezaVPN از Android 7.0 به بالا و ویندوز با نصب‌کننده‌های مستقل Native برای معماری‌های x64 و x86 پشتیبانی می‌کند.
