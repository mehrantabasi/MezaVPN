## Android

Official Android builds are distributed only through MezaVPN's GitHub Releases.

1. Open [MezaVPN Releases](https://github.com/mehrantabasi/MezaVPN/releases).
2. Choose the newest stable Android release and download its `.apk` file.
3. Compare its SHA-256 checksum with the value in the release notes, when provided.
4. Open the APK and complete the installation.
5. Approve Android's VPN permission on the first connection.

Android requirements:

- Android 7.0 (API 24) or newer
- ARM64, ARMv7, or x86_64 device
- Official package name: `com.mehransystem.mezavpn`
- Android VPN connection permission

## Windows

The Windows edition is in active development and does not yet have a public
installer. It will be published under
[MezaVPN Releases](https://github.com/mehrantabasi/MezaVPN/releases) after the
official package completes signing and release qualification.

Do not install files claiming to be MezaVPN for Windows from third-party sites
or unknown links. A Windows build is official only when it is attached to a
release in this repository.

## Updating Android

MezaVPN can notify you when an official update is available and open its
download page directly. Install the newer official APK over the existing app.
Android accepts an in-place update only when both packages use the same official
signing identity.

## If installation fails

- Confirm that the device runs Android 7.0 or newer.
- Remove unofficial or differently signed copies of MezaVPN.
- Check that enough storage is available.
- Download the APK again in case the file is incomplete.
- Report the exact Android error through
  [GitHub Issues](https://github.com/mehrantabasi/MezaVPN/issues/new/choose).

> Official MezaVPN builds are never distributed through third-party APK mirrors.
